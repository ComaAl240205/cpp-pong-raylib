# Pong Clone (Raylib)

A simple Pong game I created using C++ and Raylib.

## Features

- Two-player gameplay
- Score system
- Ball collision
- Smooth movement
- Window rendering with Raylib

## Built With

- C++
- Raylib

## What I Practiced

- Game loops
- Collision detection
- Working with vectors
- Basic game physics
- Using an external library
